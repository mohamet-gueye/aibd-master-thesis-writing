\chapter{Appendices}
\label{chap:appendices}

The appendices provide documentary support for the methodological
procedures, analytical results, simulation outputs, and decision-support
artifacts presented in the main body of the thesis. Their purpose is to
strengthen transparency, traceability, and reproducibility without
introducing new arguments or extending the interpretation beyond
Chapters~4 to~6. Detailed visualizations, complete scenario comparisons,
dashboard pages, and implementation extracts are placed here where their
level of detail would interrupt the analytical flow of the main chapters.

All numerical values, thresholds, labels, and model outputs reproduced in
these appendices are taken directly from the validated datasets, notebook
outputs, AnyLogic exports, and Power BI files produced during the study.
No value has been recalculated, rounded in a manner that changes its
meaning, or replaced with an illustrative substitute. Where a figure or
table also appears in the main text, the cross-reference is stated so that
the relationship between the summary presentation and the complete evidence
remains explicit.

The appendix structure is organized as follows: Appendix~A contains the
simulation figures; Appendix~B contains the pressure-analysis and forecast
figures; Appendix~C contains the analytical and scenario tables; and
Appendix~D contains the code and implementation extracts.
