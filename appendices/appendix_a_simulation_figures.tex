\chapter{Simulation Figures}
\label{app:simulation-figures}

Appendix A contains the complete visual record of the AnyLogic discrete-event simulation: the spatial reference used to construct the model, the implemented process layout, the running model and its control interface, and the full set of scenario-comparison outputs. The main text carries only those figures required to follow the argument (Chapter 4, Figures 4.3 and 4.4; Chapter 5, Figures 5.3 and 5.4); the remainder are reproduced here so that the simulation evidence remains complete and inspectable.
